# 学习笔记

笔记的第一读者是人。让半年后的读者不打开源码，也能重新理解这个知识点，并知道怎样把它用于判断问题。

## 写成什么

- 用一个读者关心的问题确定主线。先讲直觉和用途，再解释机制与因果，接着用具体例子把抽象概念落地；结构随主题调整，不机械套满栏目。
- 用自然中文连接段落。术语首次出现时解释含义，公式旁说明符号、单位和前提。例子有数字、条件和结果，不能只有名词和箭头。
- 删去没有信息的过场句，将“增强稳定性、实现闭环”等空评价改成具体条件、变化和结果；同一个概念用同一套术语。表格单元格写可读短句，不堆标识符。
- 保留会改变判断的边界：成立条件、反例、常见误解、现场现象。区分普遍原理、项目选择、已观察现象和仍待确认的推断；用一句贴近内容的说明即可。
- 代码只有在帮助理解机制时才进入正文，并解释它做了什么、为什么。源码文件、行号、Git、检索命令和代理分析过程不构成正文。必要来源集中在文末少量参考中，不对每句话建立证据链，也不强制附源码。
- 不把聊天中的假设、旧笔记或先前 AI 的示例写成当前项目事实。可以先完成有依据的概念解释，明确尚不能确认的项目部分；不为写一篇笔记启动全仓审计。

## 从材料到理解

先看用户材料与目标笔记；需要补充时按主题搜索相关旧笔记和必要原始资料。不要默认扫描全会话、全部工程或整本知识库。

对话转笔记时，保留促成理解的关键问题、最后成立的解释、例子和必要背景；将重复追问融入相关段落，删去工具过程和放弃的尝试。用户问题可以成为标题或讲解线索，不必逐轮复述问答。

把信息分成“要解释的现象、机制、例子、边界、知识联系”，再围绕问题重新组织。多个来源相同时合并重复；结论不同时核对条件、单位、时间和适用范围，解释为何不同。汇总必须形成新的理解顺序，不能逐篇拼接摘要。

已有同主题笔记时，优先在授权范围内修订和融合，保留有价值的解释、块引用和用户内容。整篇重写仅用于用户已授权的目标；不能因内容重复自行删除或移动其他笔记。避免每次向末尾追加一份“最新版总结”。

一个主题能独立讲清楚才拆篇，不为了原子化切碎推导和例子。系列导航按理解顺序挑选少量最佳入口，并说明“为什么先读它”；关联要讲清前提、应用、对比或反例关系，不能只罗列链接。没有目标页就写普通主题文字，不伪造双链。

需要具体写法、综合示例或验收尺度时，读 [references/writing-examples.md](references/writing-examples.md)。

按读者任务区分文档：学习笔记偏解释；教程引导初学者完成一次练习；操作指南解决具体目标；参考页便于查参数。可以相互链接，不把所有类型塞入同一模板。整理项目知识库时仅吸收与理解有关的背景、设计理由和经验，不自动建立 API、变更日志或开发者交接系统。

## 视觉与载体

需要建立思源使用规范、规划分区、减少重复或组织知识时，先读 [references/siyuan-conventions.md](references/siyuan-conventions.md)。它定义主笔记职责、标签维度、语义双链，以及嵌入、AV、模板、闪卡、资产和历史的选用与验证。用户只要求创建指导时，仅交付指导，不把发现的问题转成现有笔记修正。

默认沿用用户选择的笔记系统。先用标题、留白、少量重点、图和例子的邻接关系建立阅读层次。比较用表格，因果或过程用图，关键误解用提示块；视觉元素应减少解释负担。

思源优先使用可编辑的原生内容块；主题入口可用少量卡片或超级块，解释正文保留连贯段落。不要将整篇笔记变成图片、HTML 壳或数据库，也不要为了纸张装饰裁掉重要解释。需要排版或将 Obsidian/HTML 设计迁移到思源时，读 [references/visual-design.md](references/visual-design.md)。

写入思源时，先读 [references/siyuan-mcp.md](references/siyuan-mcp.md)，按当前会话实际暴露的工具与帮助选择 MCP。文档宣称、源码实现、当前工具可调用和本次写入读回是不同状态；不可用的 MCP 不阻塞另一个已授权可用入口，但不能借另一入口绕过权限拒绝或笔记本限制。

用户只要求整理内容时直接交付内容；要求写入思源时完成写入、图标和必要读回。技能不自行配置 MCP、改变主题、上传附件、创建数据库或安排复习；这些动作由实际需求决定，既有授权有效。

## 完稿判断

删去所有文件名、行号和 Git 信息后，读者仍应能解释“为什么、怎样工作、何时不适用”。如果剩下几乎是空壳，重写正文。

检查数字和单位能否前后一致，例子是否支撑结论，知识综合是否解释分歧，图表是否表达了正确关系。必要时加一道改变条件后的预测题，但不要把每篇笔记变成试卷。

写入后核对目标、主要正文及实际使用的引用/原生块。没有查看界面时，只报告内容或结构读回完成，不声称视觉验收通过。交付主要给笔记链接和一句说明，不把内部验证记录搬进笔记正文。

维护本 Skill 的来源取舍见 [references/sources.md](references/sources.md)，普通写作无需加载。
